Fluff-History uses the classic per-user Setup installer.

Setup and application executables are unsigned. Windows may show an unknown-publisher or reputation warning. Do not install files from an untrusted source.

The classic Explorer command is available directly on Windows 10 and through Show more options on Windows 11. The native Properties page remains available. Setup installs no package identity or certificate and requires no administrator approval for Explorer integration.

An unused exact machine certificate from an older packaged context-menu installation may remain unchanged. Current integration does not depend on that trust.

Automatic installer execution remains restricted to an approved publicly trusted signer. Install unsigned releases manually.
