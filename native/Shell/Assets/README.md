# History icon

`history.svg` is Microsoft's Fluent System Icons `History 20 Regular`, distributed under the accompanying MIT license. Source: [microsoft/fluentui-system-icons](https://github.com/microsoft/fluentui-system-icons/blob/main/assets/History/SVG/ic_fluent_history_20_regular.svg).

`history.ico` contains 16/20/24/32/48/64-pixel renderings of that geometry in neutral gray for light/dark Shell backgrounds. Regenerate on Windows with `powershell.exe -STA -File Generate-HistoryIcon.ps1`. This optional regeneration uses the Windows desktop rendering libraries; normal native builds consume the checked-in icon and require only MSVC/Windows SDK.
